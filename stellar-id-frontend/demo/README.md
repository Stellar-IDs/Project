# demo app

Next.js (App Router) demo for `stellar-id-frontend`, running against Stellar testnet.

**Status:** Phase 0 scaffold. The wallet sign-in, profile, credential issue/verify/revoke, and badge flows are implemented in Phase 5 (see `PLAYBOOK.md` §8 in the monorepo root).

## Run

```bash
pnpm dev
```

## Build

```bash
pnpm build
```

The demo is deployed to Vercel in Phase 5 with a visible "Testnet only" banner.
